# ИИ в аналитике и отчётности девелопера

Интерактивная презентация JetMetrics для конференции MIPIF: 15 слайдов, формат 16:9, продолжительность доклада — около 20 минут.

Откройте `index.html` в браузере. Кнопка «Показ» включает полноэкранный режим; для перехода между слайдами используйте стрелки, кнопки или оглавление. На телефоне доступно перелистывание свайпом. Адрес со ссылкой на конкретный слайд можно скопировать из строки браузера.

`index.html` содержит все необходимые стили, шрифты, иконки и скрипты. Для просмотра не требуются установка или сетевые запросы.

## Изменение презентации

Тексты и схемы находятся в `build.py`, логика навигации — в `app.js`, дополнительные настройки оформления — в `overrides.css`. После изменения исходников пересоберите HTML:

```sh
python3 -B build.py
```

Использованы шрифты Onest и IBM Plex Mono и иконки Lucide. Тексты лицензий находятся в `assets/fonts/` и `assets/icons/`.
